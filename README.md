Es un trabajo practito realizo para la materia "Desarrollo de Videojuegos para Dispositivos Móviles" del profesor "Rodrigo Martin Corral Fernandez"
de la carrera "Tecnicatura Superior en Programacion de Videojuegos" de la facultad Image Campus.

Se nos dio como tarea portear a dispositivos mobiles un juego realizado por el prefesor. Con el objetivo de incorporar los conocimientos brindados en clase: Como el manejo de canvas,
Adressables, carga y descarga asyncronica de escenas, Pantalla Tactil, Operadores de Preprocesamiento, Singleton entre otras herramientas y patrones de diseño.
